# Office Joke Open

One original line of office comedy. `main.ts` writes the joke to `/output/entry.txt`
(overridable via the `OUTPUT_PATH` environment variable for local testing).

The joke: a trust-fall team-building exercise where nobody catches the faller —
and HR reframes the failure as "a valuable lesson in self-reliance."
